# 모기 비행 궤적 예측 대회 - 플랜

## 문제 정의

- **입력**: 11개 시점의 3D 좌표 (t = -400, -360, ..., -40, 0 ms)
- **출력**: t = +80ms 시점의 (x, y, z) — 마지막 관측 시점 기준 2스텝 앞
- **평가**: R-Hit@1cm — 예측 오차 ≤ 0.01m 이면 적중, 전체 평균 명중률
- **핵심 난이도**: 1cm 임계값은 매우 좁음. 모기가 80ms 동안 수 cm 이동 가능

## 접근 전략

### 1단계 — 물리 기반 베이스라인 (빠르게 구현, 제출 가능한 수준)

1cm 임계값에서는 단순한 물리 모델이 종종 딥러닝보다 강함.
노이즈 필터링 + 정확한 외삽이 핵심.

| 방법 | 설명 | 예상 난이도 |
|------|------|------------|
| 등속 운동 (CV) | 최근 N스텝 평균 속도로 외삽 | 쉬움 |
| 등가속 운동 (CA) | 최근 스텝에서 가속도 추정 후 외삽 | 쉬움 |
| 다항식 회귀 | 11점에 다항식 피팅 후 t=+80 외삽 | 쉬움 |
| **칼만 필터 (CV/CA)** | 노이즈를 고려한 최적 상태 추정 | 보통 |

→ **칼만 필터(CV 또는 CA 모델)를 우선 목표로 설정**

### 2단계 — 머신러닝

- 입력 피처: 속도 시계열, 가속도 시계열, 위치(t=0), 이동 방향 등
- 타깃: Δx, Δy, Δz (t=0 대비 t=+80ms 변화량) — 절대 좌표보다 안정적
- 모델 후보: XGBoost / LightGBM (각 축 독립 예측)

### 3단계 — 딥러닝 (데이터 전체 사용 시)

- LSTM / GRU: 시계열 시퀀스 → 다음 위치
- Transformer: 어텐션 기반 궤적 인코딩
- 학습 시 주의: train/test가 다른 환경 → 일반화가 핵심, 공간 좌표 자체보다 **상대 변위(delta)** 학습 권장

## 주요 고려사항

- **상대 변위 예측**: 절대 좌표 예측보다 `(x_pred - x_0)` 예측이 환경 변화에 강건
- **노이즈**: LiDAR 센서 노이즈 존재 → 마지막 1~2스텝에만 의존하면 위험
- **1cm 임계값**: 오차 분포의 중앙값이 아니라 임계값 이하 비율이 중요 → 손실함수 설계 주의
- **train/test 도메인 차이**: 공간 외우기 금지, 상대 운동 패턴 일반화 필요

## 평가 메트릭 재확인

```python
def r_hit(pred, true):
    R_HIT = 0.01  # 1cm
    distance = np.linalg.norm(np.asarray(pred) - np.asarray(true), axis=-1)
    return np.mean(distance <= R_HIT)
```

모기 속도 ~0.3~1 m/s → 80ms 이동거리 2.4~8cm → 예측 오차 1cm 이내는 매우 도전적.
등속 가정이 맞는 경우에는 칼만 필터로 충분히 가능.
