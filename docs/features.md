# Features — make_xgb_features() 전체 목록

**총 피처 수: 424개** (v39 기준, 로컬 좌표계 기반)

모든 벡터 피처는 마지막 속도 방향을 +x축으로 정렬한 **로컬 좌표계**에서 계산된다.
